# Website Discovery, SEO & Public Performance

- Public Angular product/docs pages should use prerendering or SSR where feasible; admin routes never indexed or publicly cached.
- Unique document titles and meta descriptions; human-readable canonical URLs; accurate organization/product structured data only where applicable.
- XML sitemap of **published public** pages; robots directives to exclude administrative pages and drafts. Robots directives are not authorization controls.
- Open Graph images/description for public product pages, using approved assets only.
- Meaningful page headings, accessible alt text, logical links, content language tags and clean pagination.
- Performance: optimized images, lazy-loaded feature modules, stable layouts, cache headers that respect private/public content, responsive UI.
- Monitor Core Web Vitals; set numeric thresholds with project owners and measure on target devices.
- APK distribution pages: display compatibility, provenance, hash, official domain and release notes, without misleading download buttons.
- Versioned documentation URLs and canonical behavior for archived docs; never index confidential/internal files.
- No tracking cookies or invasive analytics until consent and privacy handling are approved.
